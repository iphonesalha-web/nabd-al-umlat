# نبض العملات

محوّل عملات وأسعار ذهب بالعربية، يعمل كتطبيق على الآيفون (PWA).

- أسعار صرف حية لـ 55 عملة، منها كل العملات العربية تقريباً، والذهب والفضة والعملات الرقمية
- رسوم بيانية بأسعار تاريخية حقيقية (أسبوع، شهر، 3 أشهر، سنة)
- سعر غرام الذهب لكل عيار وحاسبة للمصاغ
- جدول المسافر مع عمولة البطاقة
- يعمل بدون إنترنت بآخر أسعار محفوظة

**التثبيت على الآيفون:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

مصدر الأسعار: [fawazahmed0/exchange-api](https://github.com/fawazahmed0/exchange-api)
